# Personal Portfolio Website

A modern and responsive personal portfolio website showcasing my skills, projects, and experience as a Frontend and MERN Stack Developer.

## 🚀 Features

* Responsive Design
* Modern and Clean UI
* Animated Typing Effect
* About Me Section
* Skills Showcase
* Project Portfolio
* Resume View & Download
* Contact Section
* Smooth Scrolling Navigation
* Hover Animations and Interactive Elements

## 🛠️ Technologies Used

* HTML5
* CSS3
* JavaScript (ES6)
* Font Awesome Icons
* Google Fonts (Poppins)
